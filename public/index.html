Install Uptime Pulse

iPhone / iPad — Safari

  1. Tap the Share button at the bottom.
  2. Scroll and tap Add to Home Screen.
  3. Tap Add, then open it from your home screen.

Android — Chrome

  1. Tap the ⋮ menu (top right).
  2. Tap Install app or Add to Home screen.
  3. Confirm with Install.

Desktop — Chrome / Edge

  1. Click the install icon in the address bar.
  2. Choose Install.

Push alerts on iPhone only work after the app is added to your home screen.

Unlock URL management

Enter your manage key. Use the same value as CRON_SECRET from Vercel / .env.local (unless you set a separate ADMIN_SECRET).
